Claude Code SDK for C# 通过 `ClaudeCodeOptions`（核心 SDK）和 `ClaudeCodeAIAgentOptions`（MAF 集成，扩展自前者）暴露所有可调项。以下参考涵盖最常用的字段。

## 常用选项

```csharp icon=code
using ClaudeCodeSdk;
using ClaudeCodeSdk.Types;

var options = new ClaudeCodeOptions
{
    ApiKey = "sk-ant-...",
    BaseUrl = "https://api.anthropic.com",
    MaxThinkingTokens = 10000,
    SystemPrompt = "你是一名有用的助手。",
    Model = "sonnet",
    IncludePartialMessages = true,
    PermissionMode = PermissionMode.acceptEdits,
    WorkingDirectory = "/path/to/project",
    MaxTurns = 10,
    EnvironmentVariables = new Dictionary<string, string?>
    {
        { "HTTP_PROXY", "http://proxy:1080" }
    }
};
```

## 选项参考

| 属性 | 说明 |
| --- | --- |
| `ApiKey` | Anthropic API 密钥；优先级高于 `ANTHROPIC_AUTH_TOKEN` 环境变量。 |
| `BaseUrl` | 自定义 API 端点；覆盖 `ANTHROPIC_BASE_URL`。 |
| `Model` | 模型别名或完整模型名，例如 `sonnet`。 |
| `SystemPrompt` | 自定义系统提示。 |
| `AppendSystemPrompt` | 追加到系统提示末尾的附加内容。 |
| `MaxThinkingTokens` | 扩展思考的最大 token 预算（默认 8000）。 |
| `IncludePartialMessages` | 是否发送原始 `StreamEvent` 增量。 |
| `PermissionMode` | 工具权限模式：`@default`、`acceptEdits`、`plan`、`bypassPermissions`。 |
| `CanUseTool` | 处理权限请求与 `AskUserQuestion` 的异步回调，详见 [工具权限](/sdks/claude-code/configuration/permissions)。 |
| `AllowedTools` | 允许使用的工具列表。 |
| `DisallowedTools` | 禁止使用的工具列表。 |
| `McpServers` | MCP 服务器配置。 |
| `MaxTurns` | 单次会话最大轮数。 |
| `WorkingDirectory` | Claude Code CLI 的工作目录。 |
| `Settings` | 指向 settings 文件的路径。 |
| `AddDirs` | 通过 `--add-dir` 传给 CLI 的附加目录。 |
| `EnvironmentVariables` | 附加的环境变量。 |

## MAF 专用选项

`ClaudeCodeAIAgentOptions` 继承 `ClaudeCodeOptions`，额外提供：

| 属性 | 说明 |
| --- | --- |
| `ChatHistoryProvider` | 自定义历史持久化 hook；参见 [对话历史](/sdks/claude-code/maf/chat-history)。 |
