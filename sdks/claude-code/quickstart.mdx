本页面帮助你在 .NET 10.0 项目中完成 Claude Code SDK for C# 的最小可用集成，覆盖安装、鉴权和两种常见调用模式。

## 前置条件

<Steps>
  <Step title="安装 .NET 10.0 SDK">
    在开发机上安装 [.NET 10.0 SDK](https://dotnet.microsoft.com/download)。
  </Step>
  <Step title="安装 Claude Code CLI">
    SDK 通过子进程调用 Claude Code CLI，因此需要将其安装到 `PATH`：

    ```bash
    npm install -g @anthropic-ai/claude-code
    ```
  </Step>
  <Step title="配置 API 密钥">
    通过环境变量设置 Anthropic API 密钥：

    <CodeGroup>

    ```bash macOS/Linux
    export ANTHROPIC_AUTH_TOKEN="your-api-key"
    ```

    ```powershell Windows PowerShell
    $env:ANTHROPIC_AUTH_TOKEN="your-api-key"
    ```

    ```cmd Windows CMD
    set ANTHROPIC_AUTH_TOKEN=your-api-key
    ```

    </CodeGroup>
  </Step>
</Steps>

## 安装 NuGet 包

<CodeGroup>

```bash 核心 SDK
dotnet add package ClaudeCodeSdk
```

```bash MAF 集成
dotnet add package ClaudeCodeSdk.MAF
```

</CodeGroup>

## 第一次一次性查询

使用 `ClaudeQuery.QueryAsync` 发起一次性请求，通过 `IAsyncEnumerable<IMessage>` 逐条接收消息。

```csharp Program.cs icon=code
using ClaudeCodeSdk;
using ClaudeCodeSdk.Types;

await foreach (var message in ClaudeQuery.QueryAsync("法国的首都是哪里？"))
{
    if (message is AssistantMessage assistantMessage)
    {
        foreach (var text in assistantMessage.Content.OfType<TextBlock>())
        {
            Console.WriteLine(text.Text);
        }
    }
}
```

## 交互式多轮对话

`ClaudeSdkClient` 提供长连接的双向通信，可用于多轮会话。

```csharp icon=code
using ClaudeCodeSdk;
using ClaudeCodeSdk.Types;

await using var client = new ClaudeSdkClient();
await client.ConnectAsync();

await client.QueryAsync("你好，Claude！");

await foreach (var message in client.ReceiveResponseAsync())
{
    if (message is AssistantMessage assistantMsg)
    {
        foreach (var text in assistantMsg.Content.OfType<TextBlock>())
        {
            Console.WriteLine($"Claude: {text.Text}");
        }
    }
}
```

<Tip>
  所有实现 `IAsyncDisposable` 的对象都应通过 `await using` 使用，以确保子进程正确清理。
</Tip>

## 使用 Microsoft Agent Framework

如果你的应用基于 MAF，可以将 Claude 作为 `AIAgent` 使用：

```csharp icon=code
using ClaudeCodeSdk.MAF;
using Microsoft.Extensions.AI;

await using var agent = new ClaudeCodeAIAgent();

var response = await agent.RunAsync("用中文解释 C# 中的 async/await");
Console.WriteLine(response.Text);
```
