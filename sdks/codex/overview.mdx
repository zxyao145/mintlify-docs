Codex SDK for C# 通过 [OpenAI Codex CLI](https://github.com/openai/codex) 让 .NET 应用与 Codex 交互。SDK 提供 buffered turn、实时 JSONL 事件流、可恢复的 Codex thread、结构化 JSON Schema 输出、本地图片输入，以及与 Microsoft Agent Framework 的集成。AGW 内部通过该 SDK 接入 Codex Agent。

<Info>
本组文档来自 [zxyao145/codex-sdk-csharp](https://github.com/zxyao145/codex-sdk-csharp)，可以脱离 AGW 单独使用。
</Info>

## 提供的 NuGet 包

| 包 | 用途 |
| --- | --- |
| [`CodexSdk`](https://www.nuget.org/packages/CodexSdk/) | 核心 SDK：进程桥、事件模型、Buffered Turn 与流式 API。 |
| [`CodexSdk.MAF`](https://www.nuget.org/packages/CodexSdk.MAF/) | Microsoft Agent Framework 集成，将 Codex 暴露为 `AIAgent`。 |

## 支持能力概览

- Buffered turn via `Thread.RunAsync`
- 实时 JSONL 事件流 via `Thread.RunStreamedAsync`
- 可恢复的 Codex thread：`StartThread` / `ResumeThread`
- 强类型事件与 item 模型：Agent 消息、命令执行、文件变更、MCP 工具调用、Web 搜索、Reasoning、Todo list
- 通过 `TurnOptions.OutputSchema` 提供结构化输出
- 通过 `Input.FromParts`、`TextInput`、`LocalImageInput` 提供本地图片输入
- Codex CLI 配置：模型、上下文窗口、自动压缩阈值、Sandbox、审批策略、Reasoning effort、Web 搜索、附加目录、Base URL、API key、环境变量
- 通过 `CodexSdk.MAF` 集成 Microsoft Agent Framework
- 面向 `.NET 10.0`，启用 nullable reference types 与 implicit usings
