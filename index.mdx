AGW 是面向个人用户与小型研发团队的自托管**后台工程 Agent 中心**，也是一个 AaaS（Agent as a Service）平台与 Agent Gateway。用户可以在同一个界面中同时操作多个 Agent：自定义创建 Agent，或者集成 Claude Code、Codex 等外部 Agent。此外，AGW 还提供 Jobs 与 Agentflow 能力，用于创建定时任务、周期任务并对 Agent 进行编排。

<Note>
  AGW 在 1.0 之前仍在积极开发中，数据库 schema、API 与接口可能在版本间发生变化。当前尚未实现 sandbox 隔离，仅适合可信小团队或可信环境中的部署。
</Note>

## 核心能力

- **多 Agent 统一入口**：同一 UI 内使用自定义 Agent 与外部 Agent（Claude Code、Codex、Pi）。
- **Agentflow 编排**：顺序执行、扇出／汇聚、有序条件分支、交接、人工审批与受控循环。
- **Jobs**：Cron 表达式驱动的一次性、定时与周期任务，天然带有 Agent 推理与工具权限上下文。
- **跨平台客户端**：Web、Electron Desktop、Expo Mobile 共享同一批业务包。
- **A2A 协议**：通过 `Agw.A2A` 模块对外提供 A2A 协议接口。

## 配套 SDK

AGW 内部通过两个独立 SDK 接入外部编码 Agent，它们也可以脱离 AGW 单独使用：

<CardGroup cols={2}>
  <Card title="Claude Code SDK for C#" icon="c" href="/sdks/claude-code/overview">
    通过 Claude Code CLI 在 .NET 中调用 Claude，支持一次性查询、交互式会话与 MAF 集成。
  </Card>

  <Card title="Codex SDK for C#" icon="code" href="/sdks/codex/overview">
    通过 Codex CLI 提供 Buffered Turn、流式事件、可恢复 Thread 与结构化输出。
  </Card>
</CardGroup>
