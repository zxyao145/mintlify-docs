Claude Code SDK for C# 通过 Claude Code CLI 让 .NET 应用直接调用 Claude 模型。它同时支持一次性查询、长连接的交互式会话，以及作为 `AIAgent` 接入 Microsoft Agent Framework（MAF）。

## 主要特性

<CardGroup cols={2}>
  <Card title="一次性查询" icon="bolt" href="/core-sdk/one-shot-queries">
    通过 `ClaudeQuery.QueryAsync` 发起简单的请求／响应调用。
  </Card>

  <Card title="交互式客户端" icon="comments" href="/core-sdk/interactive-client">
    使用 `ClaudeSdkClient` 建立双向的多轮会话。
  </Card>

  <Card title="流式响应" icon="wave-square" href="/maf-sdks/streaming">
    通过 `IAsyncEnumerable<T>` 获取实时的 token 级增量。
  </Card>

  <Card title="Microsoft Agent Framework" icon="puzzle-piece" href="/maf-sdks/overview">
    将 Claude 作为 `AIAgent` 使用，支持会话、序列化和工具调用。
  </Card>
</CardGroup>

## 提供的 NuGet 包

| 包 | 用途 |
| --- | --- |
| [`ClaudeCodeSdk`](https://www.nuget.org/packages/ClaudeCodeSdk/) | 核心 SDK，提供进程管理、消息协议、一次性与交互式 API。 |
| [`ClaudeCodeSdk.MAF`](https://www.nuget.org/packages/ClaudeCodeSdk.MAF/) | Microsoft Agent Framework 集成，将 Claude 暴露为 `AIAgent`。 |

<Note>
  本 SDK 面向 `net10.0`，运行时需要在 `PATH` 中提供 [Claude Code CLI](https://github.com/anthropics/claude-code)。
</Note>
