本页面介绍 AGW 的本地开发环境配置、常用运行命令、调试方式与提交前校验命令。更详细的编码约定、EF Core migration 命令与 package 级任务见仓库中的 [`docs/1.Development.md`](https://github.com/zxyao145/agw/blob/main/docs/1.Development.md)。

## 前置条件

- **.NET 10 SDK**
- **Node.js 24**
- **pnpm 11.7.0**
- 构建容器镜像时才需要**带 Buildx 的 Docker**

## 首次克隆后的准备

```bash icon="terminal"
git config core.hooksPath .githooks
dotnet restore Agw.slnx
dotnet tool restore

cd src/clients
pnpm install
```

## 运行

<Tabs>
  <Tab title="后端（热重载）">
    ```bash
    dotnet watch --project src/server/Agw.Standalone.Host
    ```
    默认监听 `http://localhost:30816`。
  </Tab>
  <Tab title="Web">
    ```bash
    cd src/clients
    pnpm dev:web
    ```
    打开 `http://localhost:3001`。
  </Tab>
  <Tab title="Desktop">
    ```bash
    cd src/clients
    pnpm dev:desktop
    ```
    Renderer 使用 `http://localhost:3000`，无需额外启动 Web 开发服务器。
  </Tab>
  <Tab title="Mobile">
    ```bash
    cd src/clients
    pnpm dev:mobile
    pnpm android:mobile
    pnpm ios:mobile
    ```
    原生工程由 **Expo CNG** 生成，不应手工维护。
  </Tab>
</Tabs>

## 提交前校验

<Warning>
提交改动前请务必运行这些校验命令，避免 CI 失败。
</Warning>

```bash 仓库根目录 icon="terminal"
dotnet build Agw.slnx
dotnet test Agw.slnx
dotnet csharpier check .
```

```bash src/clients icon="terminal"
pnpm build
pnpm lint
pnpm test
pnpm fmt:check
```

修改后端 API contract 后，需要在 `src/clients` 下执行 `pnpm gen:api` 重新生成类型化客户端。

## 调试

<CardGroup cols={2}>
  <Card title="后端" icon="bug">
    在 .NET 调试器中使用 launch profile 启动 `Agw.Standalone.Host`，设置 `ASPNETCORE_ENVIRONMENT=Development` 后可访问 OpenAPI 与 Scalar 端点。
  </Card>
  <Card title="Web" icon="globe">
    `pnpm dev:web`，通过浏览器 DevTools 调试客户端；Next.js 终端查看服务端输出。指定后端：`BACKEND_API_BASE_URL=http://host:port pnpm dev:web`。
  </Card>
  <Card title="Desktop" icon="desktop">
    `pnpm dev:desktop`。Main process 输出显示在启动终端，preload 与 renderer 通过 Electron DevTools 检查。
  </Card>
  <Card title="聚焦测试" icon="filter">
    后端：`dotnet test tests/<Project> --filter "FullyQualifiedName~MethodName"`；前端：`pnpm exec turbo run test --filter=@agw/web`。
  </Card>
</CardGroup>

## 前端 Workspace 结构

`src/clients` 是由 Turborepo 编排的 pnpm Workspace：

- `web/`：Next.js Web 应用。
- `desktop/`：Electron 应用，独立 main/preload/renderer。
- `mobile/`：Expo React Native 应用。
- `packages/`：跨端共享的业务与基础设施包。

<Note>
Web 与 Desktop 不互相导入或消费对方的产物。业务模块通过 `packages/*` 复用；Mobile 只消费与 React Native 兼容的核心包。
</Note>

## 日志位置

- Server 日志：控制台 + `AgwLogDir/<Host 角色>.log`，默认 `./logs`。
- Server 状态：当前用户的 `agw` 目录下。
- Project Workspace：与日志、状态使用独立位置。
